# Design sitemap

Current designs and RFCs for statcat-serve. Each design is a page in this
directory, and its EGM review reports go in `egm/<feature>/`. A design that
changes a contract between repositories lives in the hub repository,
[StatCat-Suite/statcat-suite.github.io](https://github.com/StatCat-Suite/statcat-suite.github.io),
under `docs/design/`. The plan statcat-serve implements part of is sdmxlib's
[sharded bundle catalog plan](https://statcat-suite.github.io/sdmxlib/design/sharded-bundle-catalog-plan/),
with [its specification](https://statcat-suite.github.io/sdmxlib/design/sharded-bundle-catalog/).
